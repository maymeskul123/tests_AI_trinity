# Test17 – Влияние стоимости запроса на стратегию

**Гипотеза:**  
Quaternary, используя CONFLICT, сможет экономить дорогие запросы к идеальному источнику.

**Параметры:**
- Два источника: A (шумный, дешёвый), B (идеальный, дорогой)
- cost_B варьируется
- Бюджеты: 3,5,7,10
- Агенты выбирают источник и вопрос.
