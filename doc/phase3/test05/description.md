# Test05 — Сравнение политик на ручных сценариях

**Цель:** Сравнить четыре политики (PERSISTENT, NET, CONSISTENCY, SUPPORT) на 20 вручную заданных сценариях, где истинным кандидатом всегда является 0.

**Политики:**
- **PERSISTENT** — выбирает кандидата только с чистой поддержкой (без конфликтов).
- **NET** — использует разность support - conflict.
- **CONSISTENCY** — использует отношение support/(support+conflict).
- **SUPPORT** — использует только абсолютное количество support.
