# Phase 3 — Сравнение политик принятия решений

В Phase 3 мы перешли от сравнения агентов с разным количеством состояний к сравнению **политик принятия решений** на основе одних и тех же данных (evidence). Это позволило отделить **накопление информации** от **стратегии использования** этой информации.

## Структура Phase 3

- **test05** — Сравнение четырёх политик (PERSISTENT, NET, CONSISTENCY, SUPPORT) на ручных сценариях.
- **test06** — Статистический бенчмарк: тысячи случайных задач с контролируемыми параметрами.
- **test07** — Активное обучение: политики могут запрашивать дополнительные наблюдения.
- **test08** — Оптимизация порога уверенности для каждой политики.
- **test09** — Симуляция ИИ-программиста: уточнение противоречивых требований.

## Основные выводы

1. **SUPPORT** — лучшая политика по точности и эффективности: выбирает кандидата с максимальным количеством подтверждений, игнорируя конфликт.
2. **NET** — хороший компромисс, но уступает SUPPORT.
3. **PERSISTENT** — слишком консервативна, неэффективна.
4. **CONSISTENCY** — нестабильна, зависит от данных.
5. Для задач с возможностью уточнений (active learning) **SUPPORT** с порогом 0.5–0.6 даёт наилучший баланс.
6. В симуляции ИИ-программиста **SUPPORT** показал самую высокую точность (≈0.9) при минимальных запросах.
