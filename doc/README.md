# Документация по экспериментам с многозначными логическими системами

## Структура
В каждой папке `testXX` содержится:
- `description.md` – описание гипотезы, параметров и процедуры.
- `conclusions.md` – ключевые выводы и численные результаты.

## Итоговый вывод по всем тестам

### Основные результаты
1. **Ternary** (3 состояния) даёт преимущество в эффективности при наличии `UNKNOWN`.
2. **Quaternary** (4 состояния) обеспечивает **нулевую ложную уверенность** в условиях конфликтов.
3. **QuaternaryThreshold** (4 состояния + динамический порог) – **наилучший компромисс** между безопасностью и полезностью: он значительно снижает ложную уверенность и повышает награду по сравнению с обычным Quaternary.
4. **Quintary** (5 состояний) и **гибридные** подходы не показали улучшений в текущей реализации.

### Рекомендации
- Для задач, где критична цена ошибки (медицина, автономное вождение) → **QuaternaryThreshold**.
- Для задач, где допустимы редкие ошибки → **Ternary**.
- Для простых задач без шума → **Binary** достаточен.

### Дальнейшие направления
- Реализовать корректный гибридный агент с динамическим переключением.
- Исследовать адаптивный порог, зависящий от наблюдаемого уровня шума.
- Применить полученные состояния в нейросетевых архитектурах.
