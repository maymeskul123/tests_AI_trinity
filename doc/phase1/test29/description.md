# Test29 – Ensemble (ансамбль агентов)

**Гипотеза:**  
Комбинация трёх агентов (Binary, Ternary, Threshold) с голосованием позволит снизить ошибки и повысить точность.

**Механизм:**  
- Каждый агент работает независимо, получая одни и те же наблюдения.  
- В конце принимается решение: если все три дали одинаковый ответ – выдаём его; если два из трёх – тоже выдаём; иначе – воздерживаемся.  
- Вопросы выбираются случайным образом из предложений агентов.

**Параметры:**  
- conflict_rate: 0.0, 0.2, 0.4  
- Бюджеты: 5,7,10
