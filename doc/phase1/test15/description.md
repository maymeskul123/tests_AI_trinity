# Test15 – Активное обучение с 8 гипотезами

**Гипотеза:**  
Явное состояние `CONFLICT` позволяет Quaternary безопасно обрабатывать противоречия.

**Параметры:**
- Гипотез: 8
- Вопросов: 8
- Бюджеты: 1,2,3,4,5,6,8,10,12
- Агенты: Binary, Ternary, Quaternary
- unknown_rate и conflict_rate варьируются

**Процедура:**  
Агент выбирает вопрос, получает ответ, обновляет состояния. Quaternary использует `CONFLICT` для фиксации противоречий.
