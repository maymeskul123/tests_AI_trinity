# Финальный отчёт по исследованию многозначных логических систем

## 1. Введение
Исследовалось влияние увеличения числа состояний (2→3→4) на эффективность агентов активного обучения в условиях шума и неопределённости. Основной вопрос: **даёт ли увеличение системы счисления реальное преимущество?**

## 2. Методология
- **Агенты**: Binary, Ternary, Quaternary, QuaternaryThreshold, Quintary, адаптивные, гибриды, ансамбли, кооперативные.
- **Среда**: 16 гипотез, 8 вопросов, ограниченный бюджет, шумы `unknown_rate` и `conflict_rate`.
- **Метрики**: correct, false_confidence, abstain, reward (с высоким штрафом за ошибки).

## 3. Результаты
- **Ternary** даёт выигрыш в эффективности при `UNKNOWN`.
- **Quaternary** обеспечивает **нулевую ложную уверенность**.
- **QuaternaryThreshold** – наилучший компромисс между безопасностью и полезностью.
- Усложнения (5 состояний, адаптивные пороги, гибриды, ансамбли, кооперативные) не дали улучшений.

### Итоговая таблица (conflict_rate=0.4, budget=10)
| Агент | correct | false_confidence | abstain | reward |
|-------|---------|------------------|---------|--------|
| Binary | 0.14 | 0.86 | 0.0 | –86 |
| Ternary | 0.14 | 0.86 | 0.0 | –86 |
| Quaternary | 0.06 | 0.38 | 0.56 | –38.6 |
| **QuaternaryThreshold** | **0.017** | **0.102** | **0.88** | **–10.86** |

## 4. Рекомендации
- Для критических систем → **QuaternaryThreshold**.
- Для задач с допустимыми ошибками → **Ternary**.
- Для простых сред → **Binary**.

## 5. Заключение
Увеличение системы счисления даёт реальное преимущество в **управлении рисками** – способности избегать катастрофических ошибок. Лучшая система – **QuaternaryThreshold**.
