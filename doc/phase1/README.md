# Документация по экспериментам с многозначными логическими системами

## Структура
В каждой папке `testXX` содержится:
- `description.md` – описание гипотезы, параметров и процедуры.
- `conclusions.md` – ключевые выводы и численные результаты.

---

## Основные результаты

1. **Ternary** (3 состояния) даёт преимущество в эффективности при наличии `UNKNOWN`.
2. **Quaternary** (4 состояния) обеспечивает **нулевую ложную уверенность** в условиях конфликтов.
3. **QuaternaryThreshold** (4 состояния + фиксированный порог = 3) – **наилучший компромисс** между безопасностью и полезностью.
4. **Усложнения (5 состояний, адаптивный порог, гибриды, ансамбли) не превзошли Threshold** в данной постановке.

---

## Рекомендации

- Для критических систем (медицина, автономное вождение) → **QuaternaryThreshold**.
- Для задач с редкими ошибками → **Ternary**.
- Для простых сред без шума → **Binary**.
