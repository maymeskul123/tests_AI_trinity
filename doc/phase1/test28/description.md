# Test28 – Hierarchical (иерархическая память)

**Гипотеза:**  
Многоуровневое хранение состояний позволит агенту лучше разрешать конфликты, используя информацию на разных уровнях абстракции.

**Реализация:**  
В данном эксперименте иерархический агент был реализован как копия Threshold (из-за ошибки в коде). Фактически он не добавлял новых механизмов.

**Параметры:**  
- conflict_rate: 0.0, 0.2, 0.4  
- Бюджеты: 3,5,7,10
