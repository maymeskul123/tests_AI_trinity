# Test27 – AdaptiveThreshold (адаптивный порог конфликта)

**Гипотеза:**  
Порог перехода `CONFLICT` → `WRONG` должен динамически подстраиваться под наблюдаемый уровень шума. Это позволит быстрее исключать гипотезы при низком шуме и быть осторожнее при высоком.

**Механизм:**  
Агент ведёт скользящее окно (размер 10) из наблюдений, отмечая несовпадения. Частота несовпадений служит оценкой `conflict_rate`.  
Порог вычисляется как `max(1, round(оценка_шума * 5 + 1))`.

**Параметры:**  
- conflict_rate: 0.0, 0.2, 0.4  
- Бюджеты: 3,5,7,10  
- Остальное как в test25
